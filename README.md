# Trợ Lý Của Bà

App trên điện thoại giúp bà nội đăng bài bán hàng bằng giọng nói: chụp ảnh sản phẩm, nhân vật hỏi bà Tên, Mã, Giá, Màu, Size, rồi gửi thông tin cho Đạt qua Zalo/Messenger. Có hẹn giờ nhắc nhở hằng ngày.

Mở trên Chrome Android, bấm menu ⋮ → "Thêm vào màn hình chính" để dùng như app.

Câu hỏi nằm trong `index.html`, mục `const QUESTIONS`.
